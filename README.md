# Disclaimer

C++ is a large language that makes C++ specific ideas outside the scope of programming within other languages. C++ can be like programming multiple languages in one. You can do one thing many different ways. Having this freedom of choice puts that responsibility onto a programmer, especially a beginner.

You may be strongly discouraged with any attempt to learn this language. Not even long time C++ developers are willing to call themselves experts. There is no perfect way to do something, it is often better to accept the solution that does solve a problem rather than spending time perfecting it. 

When you begin collaborating with other developers the way you write will begin to matter. [Google's C++ style guide](https://google.github.io/styleguide/cppguide.html). As a beginner, do not stress about meeting standards or writing perfect code. Your job is to learn the syntax, control structures, and data types, then begin writing a lot of code.

This is no easy feat, when learning this language in particular you will spend the same amount of time when learning a degree or becoming a professional in a field. Nobody learns overnight. Having experience in another language helps a lot.
